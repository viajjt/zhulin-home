# 家庭管理系统（PWA）

全家共享的家庭管理应用：**日程待办 · 物品库存 · 旅行规划 · 纪念日 · 家庭点餐**。
手机 + 电脑双端自适应，本地优先存储（离线可用），可选 Supabase 免费云同步。

## 如何运行

### 方式一：本地运行（推荐先这样看）
本项目是纯静态页面，**需要本地 HTTP 服务**（直接双击 index.html 无法使用存储）。

在本目录下执行任一命令：

```
# 方式 A：使用 Python
python -m http.server 8080
# 然后浏览器打开 http://localhost:8080

# 方式 B：使用 Node
npx serve .
```

> Windows 上打开 PowerShell，先 `cd` 到本目录再执行。

### 方式二：安装为手机 App（PWA）
1. 把本目录部署到免费托管（见下）；
2. 用手机浏览器打开网址；
3. 点浏览器菜单「添加到主屏幕」，即可像 App 一样使用，**支持离线**。

### 方式三：免费部署到云端（全家手机都能用）
推荐 **GitHub Pages**（免费、HTTPS、长期稳定、国内可访问）：
1. 在 GitHub 新建一个**公开仓库**（如 `zhulin-home`）；
2. 把本目录全部文件上传到仓库根目录（或 git push）；
3. 仓库「Settings → Pages」→ Source 选 `main` 分支根目录 → Save；
4. 稍等 1 分钟，访问 `https://<你的用户名>.github.io/zhulin-home/` 即可，手机电脑都能用；
5. 手机浏览器打开网址 → 菜单「添加到主屏幕」→ 变成 App，可离线。

其他备选：Netlify（拖拽目录上传，免费）、Cloudflare Pages（免费）。
- 部署后得到公网地址，全家各设备访问即可，PWA 可安装、可离线。

## 数据说明
- 数据默认存在**浏览器本地（IndexedDB）**，换设备不互通；
- 需要**多设备云同步**时：在「设置 → 同步设置」填入 Supabase 项目地址和 anon key（免费档足够）。
  - Supabase 注册：https://supabase.com （免费，无需绑卡）
  - 创建项目 → 拿到 Project URL 与 anon key → 填入应用设置
- 「设置 → 导出数据」可随时导出 JSON 备份。

## 当前已实现（v1.0）
- ✅ PWA 骨架：可安装、离线可用、手机/电脑双端自适应、本地存储 + Supabase 同步配置入口
- ✅ 首页时尚可爱风：实时时钟（秒走）、可爱日期/星期/季节展示、实时天气（Open-Meteo 免费接口，可在设置切换城市）、动态动效
- ✅ 日程/待办：任务新建/完成/重复/指派/删除，今天/逾期/我负责的筛选；**农历日程**（如农历初一上香）
- ✅ 物品/库存：分类管理、数量增减、安全库存提醒、临期提醒、一键生成购物清单（低库存/临期 + 点餐食材待购）
- ✅ 旅行规划：目的地+时间 → 自动生成每日行程（可逐天编辑/增删天数）+ 携带物品清单（按天数×人数预填、**可自定义增删物品与数量**，含国内+出境目的地库）
- ✅ 纪念日：倒计时、编辑/删除、**农历生日**（选成员+农历月日自动换算公历，每年提醒）、大事记照片墙
- ✅ 点餐：自定义菜谱库/餐单模板（增删改）、指定开饭时间、自动采购清单、做饭排期、AI 图/成品照接口占位、允许代点
- ✅ 设置：家庭成员管理、**自定义角色**、天气城市、通知偏好、数据导出
- 🔜 预留：AI 行程生成接口、AI 菜品图接口、Supabase 正式同步逻辑

## 技术栈
原生 HTML/CSS/JavaScript（无构建依赖）· IndexedDB · Service Worker · Open-Meteo（免费天气）· Supabase（可选，免费云同步）
